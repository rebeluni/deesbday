## 🎯 CUSTOMIZATION

### Change Gradient Colors
Edit the color values in `:root` CSS variables

### Adjust Glow Intensity
Modify the `rgba()` opacity values in shadows

### Change Animation Speed
Edit the animation duration values (e.g., `15s`, `4s`)

### Add More Colors
Update the `getRandomVibrantColor()` function in `script.js`
